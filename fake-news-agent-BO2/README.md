# 📰 Fake News Detection Agent 2.0

Agent IA qui vérifie en temps réel la véracité des affirmations à l’aide de Google Gemini, SerpAPI, NewsAPI et RAG.

## 🚀 Stack Technique
- **Frontend** : Streamlit
- **LLM** : Google Gemini 1.5 Pro
- **Framework Agentique** : LangChain
- **Retrieval** : SerpAPI + NewsAPI + Chroma Vectorstore
- **Langage** : Python 3.11+
